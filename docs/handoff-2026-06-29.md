## If you need to make a structural change

### Adding a new patient-facing string
1. Add the key to `src/i18n/locales/en.json` AND `src/i18n/locales/fil.json`
2. Use `t('namespace.key')` in JSX
3. `npm run lint:i18n` to confirm no new hardcoded strings

### Adding a new component
1. Create the component
2. **Write a smoke test** under `tests/components/`. See `tests/components/README.md` for the pattern
3. Run `npm run test:components`
4. Commit (pre-commit hook will verify utils still pass)

### Adding a new Firestore query
Three things needed every time:
1. **Import**: ensure all required Firestore functions are in the import list
2. **Composite index**: if the query filters on field A AND sorts by field B, add the index to `firestore.indexes.json`; deploy with `firebase deploy --only firestore:indexes`
3. **Rule path**: ensure `firestore.rules` permits the read/write for the calling role

### Adding a new rule
1. Edit `firestore.rules`
2. Add a regression-guard test in `tests/rules/` (see existing files for pattern)
3. `npm run test:rules` to verify locally
4. `firebase deploy --only firestore:rules`
