- Wait until UTC midnight (Philippines time ~08:00) for quota reset
- For urgent writes during the day: use direct REST API (admin SDK gRPC hits the quota wall earlier)

### 4.4 Vercel deploy stuck or failed
- Check Vercel dashboard → Deployments → latest
- "Redeploy" button on the failing one
- If still stuck: revert offending commit, push, let auto-deploy take it

### 4.5 Firestore rules compile error on deploy
- Open `firestore.rules` in editor
- Run `firebase deploy --only firestore:rules` from terminal to see line/col of the error
- Fix, redeploy

### 4.6 Patient marked for deletion (race condition seen earlier this week)
- Check `users/{uid}` for `deletedAt` field
- If accidentally set: clear via Firestore console or `scripts/restore-patient.js` if you've written one

### 4.7 Mid-day quota probe fails
- Re-run after 5 minutes (transient blip)
- If still failing, check Firebase console → Usage tab for the day's totals
- Worst case: pause all non-essential writes, draft docs offline
